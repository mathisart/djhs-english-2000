# DJHS English 2000

大甲國中英文 2000 字自主學習遊戲（第一版原型）。

## 已完成
- 10 秒限時與速度加分
- 英翻中、中翻英、例句填空
- 答錯單字 1–3 題內優先重現
- 連續答對後延長複習間隔
- 熟練度：新字／學習中／待加強／已熟悉／已掌握
- 答題後顯示英文例句與中文翻譯
- Web Speech API 單字自動發音、手動重播、例句朗讀
- localStorage 保存個人學習進度
- 手機／平板／電腦響應式介面

## 下一階段
1. 匯入完整國中 2000 字官方題庫
2. 增加 A–Z／範圍／每日快練模式
3. 聽音辨字題型
4. 麥克風跟讀與基本語音辨識
5. 發音評估（需另評估語音服務與學生語音資料隱私）
6. GitHub Pages 正式發布

目前 words.js 先放少量資料作為可玩原型，方便先確認遊戲節奏與介面。
